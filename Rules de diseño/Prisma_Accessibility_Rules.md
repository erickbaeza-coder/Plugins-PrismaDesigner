# Prisma Accessibility Rules
## Reglas de accesibilidad para interfaces Prisma

## 1. Principio

La accesibilidad debe formar parte de la construcción inicial.

## 2. Contraste

Validar contraste entre:

- texto y fondo,
- iconos y fondo,
- controles y superficie,
- estados y superficie.

No utilizar color como único indicador.

## 3. Targets táctiles

Los controles deben tener un área táctil adecuada para la plataforma y contexto.

El área táctil puede ser mayor que el elemento visual.

## 4. Tipografía

- Utilizar estilos Prisma.
- Permitir escalamiento cuando corresponda.
- Evitar truncamiento innecesario.
- Probar contenido largo.
- Mantener lectura cómoda.

## 5. Estados

Cada estado debe ser distinguible sin depender exclusivamente de color.

## 6. Iconografía

Los iconos deben:

- tener significado claro,
- utilizar componentes/iconos autorizados,
- tener label cuando sea necesario,
- no sustituir texto cuando el significado no sea obvio.

## 7. Validación

El agente debe reportar:

- contraste,
- targets,
- problemas de lectura,
- dependencia de color,
- problemas de escalamiento,
- problemas de foco/interacción cuando aplique.
